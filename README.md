# FIRE for iPhone and iPad

A light IPTV player for Xtream accounts: Live TV, Movies and Series, with Continue Watching, My List, search and a live guide. iPhone and iPad, iOS 16 or later.

Your account is typed in on the sign-in screen and stays in the device's Keychain. It is not part of this code.

## Install

Download `Fire.ipa` from the latest [release](../../releases/latest) and install it with your signing app (Signulous, AltStore, Sideloadly).
